# Stock Keeper Pro

Eu quero um app de estoque que tenha como adicionar e emover pecas, fazendo a contagem de almoxarifado, com quantidade de pecas, descricao, aonde usa, foto da peca, que maquina que usa, qual linha que usa. eu preciso conseguir alimentar este estoque e conseguir fazer a localizacao de pecas, pelo nome, descricao, linha, maquina, ou ainda foto que poderia ser analisada por IA e buscar a correspondencia no banco de dados, qualquer pessoa pode entrar para visualizar, mas precisa de senha para incluir e excluir qualquer dado. adicionar no programa estes dados que estao em anexo em xls excel, sendo modelo da peca e quantidade em estoque o resto eu faco manualmente. Fazer um app bonito, responsivo e profissional. contendo este logo da Applied Nutrition. o estoque tambem deve conter estoque minimo para pedido, enviar um alerta de estoque minimo e gerar pdf do arquivo de pecas, ou ainda de pecas com estoque minimo.
